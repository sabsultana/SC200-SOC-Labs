# Lab 01 - Azure Virtual Machine Deployment

## Objective
Deploy a Windows Server 2022 Virtual Machine in Microsoft Azure and establish a Remote Desktop (RDP) connection for future Microsoft Sentinel investigations.

## Tasks Completed

- Created a Windows Server 2022 Virtual Machine
- Configured Networking
- Enabled Remote Desktop
- Connected using RDP
- Verified VM availability

## Skills Learned

- Azure Virtual Machines
- RDP Connectivity
- Azure Networking
- Azure Administration

## Outcome

Successfully deployed and connected to an Azure Windows Server VM, providing the environment required for Microsoft Sentinel and SC-200 security labs.
