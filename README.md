# SC200-SOC-Labs

## Overview
This repository documents my hands-on Microsoft SC-200 (Security Operations Analyst) labs completed using Microsoft Azure and Microsoft Sentinel.

The purpose of this repository is to demonstrate practical SOC Analyst skills, including threat hunting, incident investigation, Kusto Query Language (KQL), Microsoft Sentinel, Azure Virtual Machines, and MITRE ATT&CK mapping.

---

## Technologies Used

- Microsoft Azure
- Microsoft Sentinel
- Microsoft Defender
- Log Analytics Workspace
- Windows Server 2022
- Azure Virtual Machines
- Kusto Query Language (KQL)
- MITRE ATT&CK Framework

---

## Labs Completed

### Lab 1 – Azure VM Deployment
- Created a Windows Server 2022 Virtual Machine
- Connected via Remote Desktop (RDP)
- Explored Azure networking and VM configuration

### Lab 2 – Microsoft Sentinel Setup
- Created a Log Analytics Workspace
- Enabled Microsoft Sentinel
- Explored Sentinel workbooks and analytics

### Lab 3 – Threat Hunting
- Executed built-in hunting queries
- Reviewed KQL queries
- Investigated Windows Security Events

### Lab 4 – MITRE ATT&CK Mapping
- Explored MITRE ATT&CK tactics and techniques
- Learned how Microsoft Sentinel maps detections to ATT&CK
- Reviewed Technique T1070 – Indicator Removal
